{{ icon("i-play") }} Your day in three steps

  1. Open the Overview. Each batch shows what is happening today. Press Teach if the session is planned, or Plan today if it is not.
  2. Plan the session. Open the batch, then Today or Calendar. Add the parts you will teach, add a break or a note if you like, and press Save plan. Download PDF gives you the plan in the runbook's own style.
  3. Teach and mark done. Teach opens the day's plan. Tick each part as you finish it. It is saved at once, and Saved appears when it is safe.

Class days are set by your supervisor. A class day with no plan is shown as "not planned yet" until you save one.

{{ icon("i-book") }} Reading the runbook

  • Runbooks open in a large window as the original PDF. Scroll down to read; use the list of sections on the left to jump.
  • Open a runbook from a project name on your batch page, or from any part in the plan.
  • Add a note to any item for your own reference. Notes show on the batch page under Trainer notes.
  • Recap (in the batch's Today tab) writes a short message about what a class covered, ready to copy and send.

{{ icon("i-test") }} MCQ tests and Live Data Simulator

  • MCQ tests (batch, then Tools): open or close a test, watch students live and add time, then read results and the marks register. You can also allow a re-attempt for one student.
  • Live Data Simulator (batch, then Tools): make a join code and show it to the class. Students register once at the Register address and get their own key.

{{ icon("i-help") }} If something goes wrong

I cannot see my batch.
Your supervisor links trainers to batches. Ask them to add you.
It says no runbook is in use.
The supervisor chooses a runbook for each project. Until then, the project shows nothing to teach.
A page shows an error.
Press Go back and try again. If it repeats, send the Request ID printed on that page to your supervisor{% if support_email() %} or to {{ support_email() }}{% endif %}. It lets us find exactly what happened.
I forgot my password.
On the sign-in page press Forgot password? and use the code that is emailed to you.

{{ icon("i-settings") }} For the supervisor

  • The left menu is for monitoring only. Every change is made in Settings (account menu at the top right).
  • Runbooks: upload the Word file, check how it was read, publish it, then add the PDF so session PDFs and the reader use the original pages. Choose the runbook for each project under Courses.
  • Batches: set class days, link trainers and choose each batch's current project. You can mark a whole project complete for a batch.
  • MCQ tests (Settings) and Live Data Simulator are connected once per institution. Health shows whether they answer.
  • The Audit log records who changed what; Export downloads the data.
