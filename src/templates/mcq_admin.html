One-time set-up for an institution
  1. Open the institution's MCQ Google Sheet → Extensions → Apps Script. Add a new script file named Api and paste appsscript/Api.gs from the SkillOps folder. Save.
  2. Choose the function setupApi and press Run. Open the execution log and copy the secret (shown once).
  3. Deploy → Manage deployments → edit → Version: New version → Deploy. Copy the Web app URL (ends in /exec).
  4. Paste the URL and the secret below, Save, then press Test connection.
  5. On each batch's settings, set its MCQ batch name (the Batch column of the Students sheet).
