: practise with live business data

gives your project a database that grows while the business runs. It releases realistic business data a little at a time, as if it were happening now. You fetch the new rows through an API, load them into your own database, and watch your dashboard change.

Register with a join code Read the Developer docs

1. Register once

Your trainer shows a join code in class. Enter it with your name and roll number. You get your personal API key. Keep it secret.

2. Put the key in .env

Paste the two lines you are given into the .env file of your project, and add .env to .gitignore.

3. Write your own client

Follow the Developer docs. Start with /v1/whoami, then practise on the practice feed, then fetch your project's live data.

4. Load live data

Add a Load live data button to your Streamlit dashboard: fetch new rows, store them, run your SQL cleaning, redraw your charts.
